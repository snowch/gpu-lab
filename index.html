Who this book is for

You’re familiar with machine learning and want to understand what happens on the GPU when you run a tensor operation: how work is divided among threads, where data lives and moves, and what affects performance.

The book connects familiar ML operations to GPU architecture through small examples you can inspect and change in your browser.

Before you start

Be comfortable reading Python and working with lists or arrays, including indexing, loops and conditions. Later examples use slices and nested list comprehensions. Some experience with PyTorch is helpful.

We introduce GPU architecture and the CUDA concepts used in the chapters. C++ familiarity helps with the optional CUDA programs, but isn’t needed for the browser exercises.

All interactive examples run in your browser. No installation or GPU is required; running the downloadable programs is optional.

THE BOOK AHEAD

From tensor operations to the hardware.

Follow twelve chapters from a tensor operation to GPU execution and AI workloads. Each starts with a small example, then asks you to predict, run and explain. Extra practice is optional. The appendices provide desktop setup and the interactive GPU map.
