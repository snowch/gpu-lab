Many numbers, one calculation

A GPU can run many copies of a small program. Each copy is called a thread. Here, each thread multiplies one input number by the same amount.

In PyTorch, x holds the input numbers and y holds the results: y = x * 2.

Run to double the numbers. Then change the multiplier and run again.

The same idea in CUDA

        
This code runs inside a GPU function. input and output are arrays; i chooses an element. CUDA C++ uses ; to end a statement and 2.0f to write a floating-point number.

        

        

          
CUDA calls the block number blockIdx.x, its size blockDim.x, and a thread’s position within it threadIdx.x. The .x selects the first dimension; this example uses a one-dimensional list.

          
int i = blockIdx.x * blockDim.x + threadIdx.x;

          
The variable i is an integer. Block size is our grouping choice, not a count of physical GPU cores.

The Python operation

        
device="cuda" asks PyTorch to store the tensor on an NVIDIA GPU. PyTorch handles allocation and launches its own implementation of the operation; it does not compile the example below.

        
The complete CUDA example

        
__global__ marks a GPU kernel. void means it returns no value directly: it writes into output. float* passes the location of an array of floating-point numbers; const means this function does not change that input. n is the number of elements.

        
Run the CUDA example on an NVIDIA GPU
          
The download contains this kernel and a separate CPU-side C++ program that allocates memory, copies inputs, launches the kernel and reads the output. It is not a Python extension.

          
          
Requires an NVIDIA GPU, compatible driver, CUDA Toolkit and host C++ compiler:

          
nvcc -std=c++17 hello.cu -o hello
./hello

          
The generated CUDA program has not yet been compiled or tested on an NVIDIA GPU.

About the simulation
        
This browser model computes the illustrated operations on the CPU, including offline. It does not run PyTorch, compile CUDA or execute GPU code. The picture shows which element each thread handles, not hardware placement, execution timing or a promise that all threads run at once.
