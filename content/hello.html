CHAPTER 1

One operation, many numbers

Start with a short PyTorch program, then follow how the GPU handles its numbers. By the end, you will be able to trace one input to its output and explain why extra threads need a bounds check. Each example below keeps its own controls and results, so you can look back as you go.

Run it with PyTorch

Run the opening snippet in your own PyTorch environment with an NVIDIA GPU, then inspect y.cpu(). Chapter 2 explains that copy. The PyTorch companion checks the examples from the opening chapters and offers a CPU-only mode for checking values and layouts.

The companion’s GPU path has not yet been validated on an NVIDIA GPU. The CUDA download above is a separate handwritten implementation.

About the simulation

This browser model computes the illustrated operations on the CPU, including offline. It does not run PyTorch, compile CUDA or execute GPU code. The picture shows which element each thread handles, not hardware placement, execution timing or a promise that all threads run at once.
