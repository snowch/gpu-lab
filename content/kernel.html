Repair a kernel

Repair a kernel, explain its failures, then build vector addition.

Begin with y = 2 * x, then transfer what you learn to y = x + b: the elementwise addition used in residual connections in neural networks.

A kernel is a function run many times; one run is an invocation. An invocation with a valid element index should write one output value. Array indices start at zero.

Guided challenges

Keep investigating

  1. Pass all three lengths. Which element did the starting kernel miss?
  2. Inspect length 35. Jump to the last invocation: why does its guard skip the memory access?
  3. Remove the bounds check and run the model. Find the first invalid access, then repair it.
  4. Try the local index. Why can a single-workgroup test pass while length 35 fails?

Unsafe model configurations are stopped before WebGPU dispatch. This prototype does not execute out-of-bounds accesses or write races on your device.

What each approach establishes

Browser model: explicit indexing, guards, FP32 arithmetic, reads, writes, duplicate writes and unfilled outputs for these expressions. It does not compile WGSL, simulate SMs, caches or warps, or predict time.

WebGPU: the browser compiles the generated WGSL and dispatches it to its selected adapter. Some environments use a software adapter. Results check correctness, not speed. The replay is explanatory model state, not measured GPU internals. WebGPU workgroups play a similar role to CUDA blocks but do not promise NVIDIA’s 32-thread warps.

Both paths use the same input vectors and an independent reference calculation. There is no server, CUDA compiler or GPU account.
